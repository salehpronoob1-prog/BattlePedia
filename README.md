# BattlePedia
Standalone Minecraft Fabric 1.21.11 client mod prototype.

- Press **B** to open a transparent purple/light-blue encyclopedia shell.
- Left sidebar categories and rarity selector are placeholders for the forthcoming pet catalog importer.
- Pets can be stacked; individual abilities may have non-stacking restrictions.

## Build
GitHub Actions builds on every push and uploads the JAR as a workflow artifact.
Requires Java 21 and Fabric API at runtime.
